DI SEARCH と連携する

DI SEARCH のアカウントを THE GOSHO に登録すると、「書籍検索」タブから池田先生の著作や指導を探せるようになります。登録は 3 ステップです。

はじめにご確認ください

連携には お客様ご自身の DI SEARCH アカウント（sokadisearch.org でお使いのメールアドレスとパスワード）が必要です。THE GOSHO 側で新しくパスワードを作るものではありません。DI SEARCH のアカウントをお持ちでない場合は、先に DI SEARCH のサイトでご登録ください。

1「その他」から DI SEARCH を開く

  1. ホーム画面の右上にある丸いアイコンをタップして「その他」を開きます。
  2. 下にスクロールすると 連携 という見出しがあります。
  3. その中の DI SEARCH（未接続と表示されています）をタップします。

2メールアドレスとパスワードを入力する

  1. メールアドレスに、DI SEARCH でお使いのメールアドレスを入力します。
  2. パスワードに、DI SEARCH のパスワードを入力します。
  3. 接続するをタップします。認証が終わると「接続済み」に変わります。

3「書籍検索」タブで使う

  1. 画面下部の 書籍検索 タブを開きます。
  2. 上部で 書籍（章単位で探す）と 指導（引用単位で探す）を切り替えられます。
  3. 「幸福について書かれた指導」のように、ふだんの言葉で入力して検索します。

検索には少し時間がかかります（指導の検索は 30 秒ほどかかることがあります）。結果が出るまでそのままお待ちください。

よくあるご質問

パスワードは THE GOSHO に送られますか？

いいえ。入力されたメールアドレスとパスワードは、iOS の Keychain（端末内の暗号化された領域）にのみ保存され、THE GOSHO のサーバーには送信されません。認証は端末から DI SEARCH のサーバーへ直接行われます。連携を解除すると端末から削除されます。

接続できません

まず、同じメールアドレスとパスワードで DI SEARCH のサイトにログインできるかをお確かめください。サイトにログインできない場合は、DI SEARCH 側でパスワードの再設定が必要です。サイトにはログインできるのにアプリで接続できない場合は、お手数ですがサポートまでご連絡ください。

連携をやめたいときは

手順 1 と同じ画面（その他 → 連携 → DI SEARCH）を開くと、接続を解除できます。解除すると、端末に保存された認証情報は削除されます。

DI SEARCH のアカウントがなくても THE GOSHO は使えますか？

使えます。御書の閲覧、AI による現代語訳、用語解説、勤行・唱題の記録などは、DI SEARCH との連携がなくてもご利用いただけます。連携が必要なのは「書籍検索」タブのみです。
